Event Management System

## Description
A Simple Event Management System built with **HTML, CSS, JavaScript, and MySQL**.  
This system allows users to manage events, attendees, and RSVPs. Users can add, edit, and delete events, register attendees, and track attendance status.  
Includes sample data and interactive web pages for demonstration purposes.

## Technologies Used
- HTML
- CSS
- JavaScript
- MySQL (SQL script included)

## Project Structure
│-- events.html
│-- attendees.html
│-- rsvps.html
│-- mini_events.sql
│-- README.md

## Instructions 
1. Use the forms to add new events, attendees, or RSVPs.  
2. Tables display sample data included in the SQL script (`mini_events.sql`).  
3. For a fully functional database, run `mini_events.sql` in MySQL and connect using a backend script (optional).

## Challenges & Learning
- **Challenges:** Ensuring proper table relationships, client-side validation for forms, and maintaining a clean, readable layout.  
- **Learning:** Learned to design a small database with relationships, implement interactive forms with JavaScript, and organize multiple pages for a web-based system.
